# Кинематографичные сайты с ИИ: как это сделано

Разбор техники, которую продаёт курс «Sites Profissionais e Cinematográficos com IA»
(Construtores de IA, от $10; нейросети, домен и хостинг оплачиваются отдельно), и
рабочий прототип для AVA в этой папке: `cinematic/index.html`.

## Суть приёма

«Кинематографичный» сайт — это прокрутка, которая управляет видеороликом. Человек
листает, а камера летит над морем, наезжает на лодку, переходит к следующей сцене.
Поверх идут крупные титры. Тяжёлого 3D здесь нет, это обычный короткий ролик.

```
1. Кадры-ключи        →  2. ИИ-видео между ними  →  3. Нарезка на кадры  →  4. Прокрутка = кадр
Nano Banana / Higgsfield   Kling / Veo / Seedance     ffmpeg → 120–400 WebP    canvas + GSAP ScrollTrigger + Lenis
(или реальные фото)        5–10 сек, 16:9 и 9:16      ~5–10 МБ                 + титры, пины, раскрытия
```

1. **Кадры-ключи.** Генерируем или берём фото: начальный и конечный кадр каждой сцены
   (утро — лодка, день — скалы, вечер — спа).
2. **Видео между ключами.** Модель image-to-video (Kling, Veo, Seedance через Higgsfield)
   делает плавный пролёт от первого кадра ко второму. Обычно 5–10 секунд. Под телефон
   нужен отдельный вертикальный вариант 9:16.
3. **Нарезка.** ffmpeg режет ролик на WebP-кадры. Это надёжнее, чем `video.currentTime`:
   видео при перемотке назад на iPhone дёргается, а кадры на canvas — нет.
4. **Сборка страницы.** GSAP ScrollTrigger переводит прогресс прокрутки в номер кадра.
   Lenis делает прокрутку плавной. Секции закрепляются (`position: sticky`), титры
   появляются по главам. Дальше стандартные приёмы: горизонтальная лента, раскрытие
   картинки через `clip-path`, параллакс.

Код обычно пишет ИИ-агент (Claude Code, Lovable) по готовому шаблону-навыку. Есть
открытые навыки ровно под это: `mannarch/cinematic-scroll-site`,
`sergeyramas/3d-website-builder-skill`, `roeea2/scroll-site-claude`.

## Что в прототипе

| Приём | Где |
|---|---|
| Прокрутка листает «фильм» из 152 кадров на canvas | раздел «Остров в кадре» |
| Титры по главам: утро → день → вечер, полоса прогресса | там же |
| Прогрессивная загрузка: сначала каждый 8-й кадр, потом остальные. Листать можно сразу | JS `load()` |
| Горизонтальная лента услуг с параллаксом внутри карточек | «Всё на острове» |
| Раскрытие кадра на весь экран + слова по одному | «Ваш остров начинается здесь» |
| `prefers-reduced-motion`: без анимаций, обычная страница | CSS/JS |

Библиотеки лежат локально в `vendor/` (GSAP 3.12.5, Lenis 1.1.13), без внешних CDN.

**Сейчас «фильм» собран бесплатно из ваших фото** (`build_frames.py`: наезд камеры,
панорама, наплыв между планами). Это честная замена ИИ-видео, но движение — только
камера над статичной картинкой. Настоящую «киношность» (бегущая вода, лодка в движении)
даёт ИИ-ролик.

## Как заменить на ИИ-видео

```bash
# 1. Получить ролик (Higgsfield/Kling): 5–10 c, 1280×720; для телефона — второй, 720×1280
# 2. Нарезать кадры (страница подхватит сама, число кадров берётся из manifest.json)
python3 cinematic/build_frames.py --video hero.mp4 --fps 24
```

Ориентир по цене: ~$1–1,5 за ролик Kling/Seedance через Higgsfield (по сторонним
разборам). Higgsfield подключён к вашему аккаунту, но генерация платная. Без
согласования я её не запускал.

## Что доделать для боевой версии
- Свои кадры: виллы AVA, рассвет, катер в движении. На фото сейчас чужая лодка
  (Go Sea Marine) и стоковые картинки.
- Вертикальный ролик и отдельный набор кадров для телефонов: сейчас кадр 16:9 сильно
  обрезан по бокам.
- Вес: 152 кадра ≈ 7 МБ. Для мобильных — кадры 960 px и качество 50 (≈3 МБ).
- Шрифты Cormorant Garamond/Inter грузятся с Google Fonts. Для приватности их можно
  положить локально.
- Кнопку «Открыть консьерж» связать с чатом или WhatsApp.
